# SBOM: software bill of materials

Cross-ecosystem dependency inventory with resolved licenses, organized by
crate / app / service. Generated by [ORT](https://github.com/oss-review-toolkit/ort)
(OSS Review Toolkit). This is **transparency only**: it is additive and
**non-gating**; `cargo-deny` remains the supply-chain gate.

## Regenerate

```bash
just sbom                      # pinned ort-minimal image (default), via podman/docker
ORT_VERSION=84.0.0 just sbom   # pin a different ORT version
ORT_IMAGE=ghcr.io/oss-review-toolkit/ort just sbom   # full image, if ever needed
```

Runs the ORT Analyzer + Reporter inside the `ghcr.io/oss-review-toolkit/ort-minimal`
container, with no host JVM. It covers Cargo, npm (from `apps/frontend`'s committed
`package-lock.json`) and pip (from `apps/hayhooks`' hash-locked `requirements.txt`, the
cognition runtime image). First run pulls the image (~3 GB) and may need network.

## What lands here

| Path | Committed? |
|------|------------|
| `report.html` | **yes**: the human-readable, by-crate/app/service, by-license view |
| `README.md` | **yes** |
| `bom.cyclonedx.{json,xml}` | no: consolidated CycloneDX (generated) |
| `*.spdx.{yml,json}` | no: consolidated SPDX (generated) |
| `crates/<x>/`, `apps/<x>/`, `services/<x>/` | no: per-project BOM + `licenses.tsv` (generated) |
| `.ort/` | no: ORT working dir (generated) |

Everything except the report and the README is gitignored; regenerate to
view it. An SBOM is generated, never hand-edited.

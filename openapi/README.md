# API contract: OpenAPI

The API contract is generated by the backend from its own handlers (Rust +
[utoipa](https://github.com/juhaku/utoipa)). Code is the single source of truth,
not a hand-maintained collection.

- Commands (REST): `GET /api/openapi.json` serves the OpenAPI 3.1 document.
- Reads (GraphQL): `POST /api/graphql`, a read-only surface with no mutations.

There is no bundled docs UI.

## Bring your own client

No API client collection is committed. Point any tool at the endpoints above:

- Bruno (MIT, git-friendly, offline): https://www.usebruno.com
- Hoppscotch (MIT, self-hostable): https://hoppscotch.io
- `curl`, or a Swagger UI / Scalar instance of your own for exploration.

## Committed snapshot + drift gate

The committed, drift-checked snapshot is `apps/frontend/openapi.json` (beside the read
surface's `apps/frontend/schema.graphql`): the contracts the frontend's typed clients are
generated from. `just frontend-contracts` exports both from code (no running backend)
and regenerates the clients. The backend test `contract_snapshots` (`cargo test`) fails
when a committed snapshot drifts from what the code generates, and `just frontend-check`
fails when the clients drift from the snapshots.
